# 📚 Biji - 机器学习与深度学习笔记库

这是一个收集机器学习、深度学习、物理信息神经网络(PINNs)和 Transformer 相关论文笔记的知识库。

## 📖 内容概览

### 时间序列模型
- AR、MA、ARMA 等 10 类时间序列模型
- NARX 模型的原理和代码

### Transformer 相关
- Transformer 代码实例
- PINNsFormer - 基于 Transformer 的物理信息神经网络
- PDE-Transformer - 用于物理模拟的通用 Transformer
- 思维链赋予 Transformer 解决串行问题的能力
- 更多 Transformer 应用论文...

### 物理信息神经网络 (PINNs)
- NSFnets - 用于 Navier-Stokes 方程的 PINNs
- PhysicsSolver - 基于 Transformer 增强的 PINNs
- Transolver - 用于通用几何域 PDE 求解的 Transformer 模型

### 其他领域
- 化学反应预测
- 无人机控制
- 计算机视觉
- 通讯领域应用
- 学术论文写作规范
